# Feedback

Si estás usando el asset en un proyecto real, el feedback es bienvenido.

Puedes escribir sobre:

- bugs y regresiones
- partes poco claras de la documentación
- decisiones de API o de arquitectura incómodas
- casos de uso que el asset aún no cubre bien
- ideas de mejora y sugerencias de funcionalidades

## Qué es útil incluir

Si estás informando de un problema, ayuda incluir:

- una descripción breve del escenario
- el comportamiento esperado y el comportamiento real
- versión de Unity
- pasos para reproducir
- capturas, vídeo o stack trace si están disponibles

Eso hace que investigar el problema sea mucho más fácil.

---

## Feedback especialmente útil

- lugares donde `DataBinding`, rules o strategies resulten incómodos
- escenarios de trading, equipamiento, world loot o inventarios guiados por servidor
- puntos dolorosos de integración con modelos de datos personalizados
- sugerencias sobre documentación, ejemplos y diagramas visuales de flujo
