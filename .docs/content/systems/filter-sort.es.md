# Filter y Sort

El paquete incluye una capa simple de filtros y ordenacion para UI.

## Piezas principales

- `FilterPreset`
- `SortPreset`
- `FilterButton`
- `SortButton`
- `FilterSortController`

## Casos de uso

- mostrar solo consumibles
- ordenar por nombre
- ordenar por tipo o categoria

Si necesitas logica mas compleja, usa estas piezas como punto de partida y adapta los criterios a tus interfaces de item.
