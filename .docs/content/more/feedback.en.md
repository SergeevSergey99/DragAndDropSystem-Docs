# Feedback

If you are using the asset in a real project, feedback is welcome.

You can write about:

- bugs and regressions
- unclear parts of the documentation
- inconvenient API or architectural decisions
- use cases the asset does not cover well yet
- improvement ideas and feature suggestions

---

## Contact

- GitHub: [https://discord.gg/HXf6Wv6UTx](https://discord.gg/HXf6Wv6UTx)

---

## What is useful to include

If you are reporting a problem, it helps to include:

- a short scenario description
- expected behavior and actual behavior
- Unity version
- reproduction steps
- screenshots, video, or stack trace if available

That makes issues much easier to investigate.

---

## Especially useful feedback

- places where `DataBinding`, rules, or strategies feel awkward
- trading, equipment, world loot, or server-driven inventory scenarios
- integration pain points with custom data models
- suggestions for documentation, examples, and visual flow diagrams

If more contact channels are added later, they will be listed on this page.
