# Demo4 Trading

Este ejemplo muestra un flujo de comercio entre inventarios con modelos de item diferentes.

## Que demuestra

- conversion entre adapters
- validacion por precio y dinero
- inventario del jugador
- inventario del comerciante
- equipamiento como slots fijos

## Archivos utiles

- `PlayerInventoryDataBinding.cs`
- `MerchantInventoryDataBinding.cs`
- `EquipmentInventoryDataBinding.cs`
- `TradingHelper.cs`
- `ModelItemAdapterConverter.cs`
- `MerchantItemAdapterConverter.cs`

## Cuando usar este ejemplo

Usalo si la misma operacion de transferencia debe producir efectos de dominio, conversiones de tipo o comprobaciones economicas.
