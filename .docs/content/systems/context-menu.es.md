# Context Menu

El sistema de context menu permite exponer acciones por item o por slot.

## Piezas principales

- `IContextMenuEntry`
- `ContextMenuEntryDefinitionSO`
- `ContextMenuManager`
- `ContextMenuPreset`

## Uso tipico

- abrir contenedor
- ordenar inventario
- ejecutar accion de debug
- acciones de uso, equipar o inspeccionar

## Recomendacion

Usa menu entries basados en assets cuando quieras configuracion reutilizable. Usa scene entries cuando dependan de referencias runtime de la escena.
