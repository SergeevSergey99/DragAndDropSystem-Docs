# Ejemplos

Esta seccion resume las escenas de ejemplo incluidas en `Examples/`.

El objetivo no es mostrar una unica arquitectura correcta, sino patrones de integracion que puedes adaptar a tu proyecto.

## Ejemplos incluidos

### [Demo1 Inventories](demo1-inventories.md)

Usalo para:

- inventario simple basado en lista
- entender `ListInventoryDataBinding`
- ver reglas y drop areas basicas

### [Demo2 Loot](demo2-loot.md)

Usalo para:

- flujo mundo -> evento -> UI -> inventario
- cofres e interaccion con objetos del mundo
- pickup y drop conectados a objetos 3D

### [Demo3 Minecraft](demo3-minecraft.md)

Usalo para:

- inventarios indexados por slot
- crafting grid con slot de resultado
- reglas por slot y limites de stack

### [Demo4 Trading](demo4-trading.md)

Usalo para:

- trading con conversion de modelos de item
- validacion por dinero y precio
- inventario del jugador, comerciante y equipamiento

### [Demo5 Containers](demo5-containers.md)

Usalo para:

- items que contienen su propio inventario
- nested containers
- apertura via context menu

## Como elegir

| Si necesitas | Empieza por |
|---|---|
| inventario simple | Demo1 |
| cofres y loot del mundo | Demo2 |
| crafting grid | Demo3 |
| trading y economia | Demo4 |
| contenedores anidados | Demo5 |
