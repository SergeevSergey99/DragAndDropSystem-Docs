# Demo5 Containers

Este ejemplo muestra items que contienen otro inventario.

## Que demuestra

- nested containers
- apertura de contenedores via context menu
- cambio del contenedor activo en la UI
- proteccion frente a ciclos invalidos

## Archivos utiles

- `ContainerDemoManager.cs`
- `ContainerUIController.cs`
- `ContainerInventoryDataBinding.cs`
- `PlayerContainerInventoryDataBinding.cs`
- `OpenContainerMenuEntrySO.cs`

## Cuando usar este ejemplo

Es la referencia correcta si necesitas mochilas dentro de mochilas, cajas, bolsas o cualquier item que actue como contenedor.
