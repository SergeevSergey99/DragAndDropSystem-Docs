# Demo2 Loot

Este ejemplo conecta el inventario del UI con objetos del mundo.

## Que demuestra

- cofres
- world loot
- world drop
- apertura y cierre de UI por interaccion
- bindings separados para jugador y cofre

## Archivos utiles

- `Chest.cs`
- `PlayerInteraction.cs`
- `LootUIController.cs`
- `WorldItem.cs`
- `WorldDropZone.cs`

## Cuando usar este ejemplo

Usalo si tu juego necesita abrir inventarios de cofres, recoger objetos del suelo o devolver items al mundo 3D.
