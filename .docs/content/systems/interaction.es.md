# Interaction

El sistema de interaction traduce input a acciones sobre slots e inventarios.

## Piezas principales

- `InteractionBindingsProfile`
- `InputEventRouter`
- `SlotInputAdapter`
- `SlotInteractionActions`

## Soporta

- pointer input
- navigation input
- bindings por tecla
- `InputAction`
- hold-to-drag

## Nota

El core funciona sin el nuevo Input System. Las partes basadas en `InputAction` requieren `com.unity.inputsystem`.
