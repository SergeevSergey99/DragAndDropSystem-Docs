# Free Form Layout

No todos los inventarios tienen que usar un grid regular.

`FreeFormSlotLayout` permite organizar slots de manera mas libre.

## Util para

- layouts diegeticos
- inventarios con forma personalizada
- UI donde la posicion visual tiene un diseno no uniforme

## Nota

El layout visual y la logica de transferencia son capas distintas. Puedes cambiar la disposicion de los slots sin reescribir el pipeline de transferencias.
