# Demo3 Minecraft

Este ejemplo se centra en inventarios indexados y crafting.

## Que demuestra

- `SlotIndexedInventoryDataBinding`
- hotbar e inventario principal
- crafting grid
- slot de resultado de crafting
- manager de recetas como fuente de verdad del dominio

## Archivos utiles

- `CraftingManager.cs`
- `CraftTableDataBinding.cs`
- `CraftResultDataBinding.cs`
- `MainInventoryDataBinding.cs`
- `HotbarDataBinding.cs`

## Cuando usar este ejemplo

Es el mejor punto de partida si necesitas grids fijos, crafting recipes o slots con significado posicional.
