# Планы на будущее

Если ассет окажется полезным и интересным для достаточного числа людей, я планирую развивать его дальше.

Сейчас среди наиболее вероятных направлений:

- поддержка `UI Toolkit`
- поддержка предметов сложной формы

Под предметами сложной формы здесь имеются в виду сценарии, где предмет занимает не одну ячейку, а более сложный набор клеток, как в grid-based inventory системах.

## Идеи для развития

Если у вас есть свои предложения по развитию ассета, их тоже можно присылать через указанные способы обратной связи.

Особенно полезны:

- реальные сценарии из проекта, которые сейчас покрыты недостаточно хорошо
- идеи по новым системам, интеграциям и примерам
- пожелания по API, расширяемости и UX

Контакты и каналы для связи перечислены на странице `Feedback`.
