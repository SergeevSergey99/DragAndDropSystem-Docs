# Selection

La seleccion multiple permite trabajar con varios slots a la vez.

## Piezas principales

- `SelectionManager`
- `SelectionContext`
- `SlotSelectionView`
- operaciones de seleccion

## Capacidades

- seleccionar un slot
- alternar seleccion
- seleccionar rango
- seleccionar todo
- iniciar multi-drag desde la seleccion

## Cuándo usarlo

Activalo cuando el proyecto necesite operaciones masivas o una experiencia de inventario cercana a RPG/ARPG/looter.
